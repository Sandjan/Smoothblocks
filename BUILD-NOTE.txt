SmoothBlocks 1.0.0-alpha.1 - initial versioned alpha

This source package targets Java 25 / Minecraft 26.1.2.

The original development environment used JDK 21 for dependency-free checks.
On 2026-10-07 a complete offline build with Java 25 and Gradle 9.8.0 passed.
This alpha preserves the internal 1.6.3 rendering implementation and known bugs.

Validated locally:
- 1,000 random opaque images / 261,078 texels: metadata bit-identical to v1.6.2.
- alpha diagonal edge is detected while hidden RGB under alpha=0 is invariant.
- Iris patch harness patches all direct main() diffuse reads but leaves helper probes untouched.
- atlas mapping / RG8UI byte-packing stress harness still passes.

Build on the target machine:

  .\gradlew.bat clean build

Expected output:
  build/libs/smoothblocks-1.0.0-alpha.1.jar
